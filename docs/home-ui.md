# GameBuddy 首页与改名（2026-10-28）

## 首页

参考用户提供的布局，采用 GameBuddy 自己的品牌与原创 SVG 龙虾，不复用其他产品的商标或机器人图片。

- 中央标语：**GameBuddy，陪你玩，帮你干。**
- 标语下「游戏 / 工作」切换，默认游戏。仅改变快捷任务展示，不裁剪 Agent 的工具或权限。
- 编辑框上方显示真实**已安装**的游戏/脚本包；已停用的包仍显示状态，不把未安装包冒充下载完成。空列表可进入游戏市场。
- 点游戏只展开能力；悬停具体任务时，在编辑框里预览示例；点击只通过原生输入动作填入可编辑草稿，不提交。任务列表位于编辑框下方，符合参考布局。
- 游戏场景：明日方舟收菜/换班配置/材料刷取/领奖/日程；Minecraft 连接/观察/移动/有界采集；龙虾杀开局/人设/好友房/续局。需要环境或玩家选择时由 Buddy 对话确认，不暗示未配置即可直接成功。
- 工作场景：写作整理、查资料、分析数据、写代码、排查问题、规划任务。
- 小龙虾在编辑框上沿，不拦截鼠标或遮挡输入。模型、权限、附件、工作区、Agent 预设、指令/引用仍由原生工作台管理。

## 示例预览、填入与手动发送（2026-10-28 最新交互）

- 悬停或键盘聚焦任务按钮：在原生编辑框内显示灰色示例预览，不修改 Lexical 草稿，不调用模型，不启动游戏。移开后恢复原提示或原草稿。
- 点击：用当前会话的原生编辑动作填入示例并聚焦编辑框；用户可直接修改。按钮不再调用 submit。
- 只有用户手动点击原生发送按钮或使用原生提交快捷键，才发送实际编辑后的草稿，继承当前模型、工作区、权限和正常提交/错误处理。
- 可以切换未改动的生成示例；已经自行编辑的文字、文件、引用、命令模式或进行中的提交不被示例覆盖。
- 原生插入使用捕获的草稿版本进行 CAS 校验，避免旧 UI 快照覆盖新编辑。预览按会话/游戏或工作分类隔离，迟到的 mouse-leave 不擦除另一任务的预览；切换会话、分类、草稿修改或卸载后清理预览。
- 尚未选择工作区时仍可浏览能力，但需要先选工作区才能填入示例。悬停预览层不拦截鼠标、不参与模型请求或草稿持久化。

这是对上一版“点击直接发送”的替换，不是增加第二种自动发送入口。原生空白会话首次手动提交后可能转成正式会话标识；验收依据实际消息及工作区，不假定占位 ID 永不变化。

## 插件拥有能力描述

各包的 `D:/Gameguy/packages/plugin-<id>/home.json` 定义 `actions[{id,label,prompt}]`。构建校验长度、结构及唯一 ID，嵌入包 manifest 和受信 catalog；安装时对比，绑定 manifest SHA-256 完整性。

前端只展示已安装包的元数据，不用游戏名分支实现玩法。新包可提供 home 元数据；缺失时仅提供“读取 Skill、了解能做什么”的通用入口，不编造游戏能力。脚本包作者描述中也支持可选 home 字段。

本次分发包版本：明日方舟 0.3.7、Minecraft 0.3.2、龙虾杀 0.3.1。只补充能力入口元数据，执行合同和权限不扩张；旧版本安装目录保留，启用 ID、配置和日程保持兼容。当前仍为内置离线市场，没有上线远程下载。

完成当前任务后退出并重新启动，加载新 UI 与身份；本轮未关闭现有游戏或应用。

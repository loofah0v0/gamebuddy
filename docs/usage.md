# GameGuy v0.3 使用说明

当前是独立桌面开发原型，不是 DSH 插件。以下按当前接口描述；真实游戏端到端验收尚未完成。

## 1. 启动、工作台与模型

双击 `D:\Gameguy\Start-GameGuy.cmd`，或在项目目录执行 `npm.cmd start`。首次源码安装用 `npm.cmd ci` → `npm.cmd run build`，需要 Node 24+；MAA worker 需要 Python 3.12+。不要求启动原版 DSH Desktop。已有旧应用不被开发测试强制重启，请自行托盘退出后重新打开加载新版。

主窗口是 GameGuy 自有 Electron 承载的完整 DSH 原生工作台，默认工作区在 `%APPDATA%/GameGuy-v03/workspaces` 下，不是源码根目录。工作区可在原生 sidebar 管理/选择。主聊天与游戏使用同一 native session；游戏中心是配置、插件、设备与日程的辅助窗口，不再是主聊天客户端。

### 模型连接和切换

1. 主窗口 **设置 → 模型 → 添加模型提供商 → 自定义模型 API**。填写 ID、显示名称、Base URL 与 Key，获取可用模型并添加；不支持目录时手填服务商准确 ID。
2. 原生设置保存多提供商、默认模型，在线更新不重启 Host。重启时保留用户原生 profile，不重新写回快捷配置。
3. 已有对话输入框旁选择当前会话模型；原生 `/model` 与选择器共用目录。切换不清历史、不改变其它会话，在途请求保持旧模型，下一次组装生效。reasoning 仅显示 adapter 明确支持的强度。
4. Key 通过 safeStorage 加密 vault 保存，不能在聊天里发送；原生设置仅持有凭据引用，加密失败不降级为明文。

原生表单包含 completions、responses、Anthropic 等选项，本轮本地端到端只测 completions；未保证每个外部端点、工具、视觉或协议均可用。

### API 推理验证快捷入口

游戏中心的“模型与应用设置”保留 URL 添加、目录获取与“验证 API”，仅管理 `GameGuy API` 快捷路由，不覆盖其他原生 provider。目录获取不是推理验证。

填服务商 Base URL（如 `https://your-endpoint.example/v1`，不是网页或完整方法地址）与 Key → 获取目录/手填 ID → 验证 API → 保存。验证发送一次短文本请求，可能产生少量 Token 费用，不发送历史/游戏数据。探测只检查草稿，不启动游戏/写配置；保存要求活动任务先停止，主窗口可以重新加载但不重启 native Host。保存成功也不代表推理验证通过。

快捷入口支持 HTTPS 和 localhost/127.0.0.1/[::1] 的本机 HTTP，拒绝 URL 凭据/query/hash/控制字符。同一路由留空 Key 保留旧值，改服务商或 URL 必须新填；不回显已存密钥。输入变化、重开和失败撤销旧验证状态。在途旧结果不会套用新草稿。原生 provider 的协议/地址支持以其表单为准，不把快捷入口规则冒充全局规则。

### 通用 Agent 交互

原生流式 Markdown 对话、附件/引用、slash picker、计划/goal/todo、工具/子 Agent/jobs/轨迹、会话搜索/重命名/置顶/fork/归档及导出模块已接入。右侧可打开文件/终端/文档/diff/隔离浏览器；主题、语言、快捷键、Agent 预设和通用插件/MCP 在原生管理页。复杂文件格式、真实附件上传、外部 MCP 认证及完整子 Agent UI 是专项测试范围；不是都已 E2E。

游戏现场按钮打开同一会话的审批、游戏画面、隐私暂停、停止和结果。游戏中心的任务提示只转入主窗口草稿，不自动发送/执行。完整接入与验收区分见 [DSH 对照](dsh-parity.md)。

## 2. 一句话委托与插件

> 帮我配置明日方舟收菜，官服，不吃药、不用源石、不购物。先检查 MuMu 和连接，让我确认登录后再执行。

Agent 通过目录/Skill 判断能力，对缺失的 MAA/Minecraft 插件提出启用审批，由插件自动发现 MuMu/MAA/ADB/Python、返回建议配置，只询问未解决的实例/渠道/依赖项，批准保存后诊断，再请求执行计划确认。刷关、换班方案和消费策略是执行前的另一步，不应阻断单纯连接。配置页是补充，不是必经路径。

### 用玩家语言配置 MAA

- “收菜，加普通自动换班，1-7 最多三次，不吃药不购物。”
- “只领日常和周常，不收邮件，不动基建。”
- “收好友信用，不购物。”
- “萨米肉鸽一局，最多半小时。”

明日方舟插件自带 Skill 与官方脚本参考。Agent 理解原话后调用 `gameguy_prepare`，由插件生成完整配置提案、有限任务链和玩家可读摘要。缺关卡/次数/肉鸽主题等信息时先问清，整份计划未解决前不执行部分任务。提案不会保存配置、启动设备、操作游戏或创建日程；首次绑定/配置变化需要配置审批，运行仍有独立审批。

普通自动换班不需要方案文件，由 MAA 选择干员；可能改变现有进驻阵容，不保证最优。复杂自定义换班才需要已有受授权方案。只说“收菜”默认领取日常/周常、邮件、好友信用，不默认加入换班、刷关、购物或肉鸽；GG 应说明这一范围，可按你的要求组合增加。官方支持的操作不等于插件全部已支持。

目录目前是应用附带的本地可信包，**不会已经从远程市场下载插件**。用户也可在“Skills 与插件”页手动启用/禁用。龙虾杀直接使用原官方 Skill，没有第三个 GameGuy 插件。启用插件不自动安装 MAA、游戏或模拟器；依赖安装自动化尚待完善。

GameGuy 业务工具参数使用外层 `input`；DSH 原生通用工具保持自己的 schema。`gameguy_setup` 可指定 `{game,instance?}`，`gameguy_configure` 使用 `{game,instance,config}` 完整配置；后续 `run/diagnose/status/stop/device_start` 只操作当前任务绑定实例，参数中不再传任意 `instance`。

### 2.1 原生权限、追问与游戏审批

主窗口保留原生全局默认和当前会话权限：只读、工作区写入、完全访问及单次授权；默认目录是当前原生工作区。原生追问与计划审阅沿用 DSH UI，skip/停止/过期不批准计划。游戏配置、设备启动、执行、消费与日程确认另走 GameGuy 卡片，不被完全访问自动批准。

通用文件/PowerShell/搜索/Skill/jobs/子 Agent 不因游戏被隐藏。原生 shell 在 Windows 保留 restricted-token/ACL runner；文件写有围栏，读取不是秘密隔离。可信宿主、插件和 Monitor 不在通用工具沙箱中。自写脚本能用于修复，但不自动继承插件资源策略、停止、互斥或 schedule 约束。兼容服务 Key 不转交 DeepSeek 搜索，未配置 provider 时搜索准确失败。

## 3. MuMu、连接与人类预览

本机已有 MuMu，不要再次下载/重装。先对 Agent 说“帮我连接明日方舟”，插件会检查有限安装位置并读取官方实例信息；只有一个实例时建议直接选用，多实例仅让你选名称/索引，无需自行寻找 CLI 路径。本机只读验证发现 `D:/MuMuPlayer/nx_main/mumu-cli.exe`、实例 0，仍需确认官服/B服。也可在插件页点击“自动发现与建议配置”。

发现不会启动设备或自动保存。审批卡确认建议配置后，再单独确认启动；下面只是得到的 emulator 配置示例，不是首次必填表单：

```json
{"emulator":{"type":"mumu","cliPath":"D:/MuMuPlayer/nx_main/mumu-cli.exe","instanceIndex":0}}
```

这是配置片段，不是完整 configure 参数。未配置 emulator 时可手动启动设备，填写实际 ADB 地址。默认 `127.0.0.1:16384` 只是默认值，不是本机连接证据。

Agent 调用 `gameguy_device_start`，或用户在游戏与设备相关入口请求启动；先在 GameGuy 确认程序路径和选定实例，5 分钟审批有效。确认后运行官方 CLI，等待选定 Android 实例就绪并取得真实 ADB 端点，再由项目 ADB 检查。120 秒内失败会明确报告，不猜端口、不替换到其他设备。

Agent 通过 `gameguy_status` 轮询当前实例的设备状态，starting 不等于 ready，失败/停止不等于已连接。ready 只表示设备连接与配置保存，不表示游戏已安装/登录、MAA 可完成任务。后续仍需诊断游戏环境。停止会取消等待/后端，**不自动关闭已经启动的 MuMu**。

主工作台右侧显示 ADB 图像，仅游戏现场可见且非隐私时采集，尝试至少间隔约 7 秒，实际耗时可能更长；状态轮询约 2 秒。辅助游戏中心的采集间隔仍约 3 秒。这是 GameGuy 内的启动入口与截图预览，不是 MuMu Windows 窗口嵌入或视频直播。外部 MuMu 窗口仍用于用户直接操作。右侧图像不自动发送给模型，当前没有 MAA 专用 Agent 设备看图/点击接口；通用 read_image 读取文件不等于设备控制。

## 4. 登录与隐私

先停止自动化，等待清理；开启界面的隐私暂停，再由用户在模拟器输入密码/验证码、扫码或实名验证。不在聊天里传秘密，不用 shell/其他截图工具绕过暂停。用户确认敏感输入结束后，在非敏感页恢复预览与执行。

隐私暂停立即清除当前游戏画面、隐藏官方观战页并阻止受管理截图和新动作，等待当前任务停止；失败时仍保持暂停。没有绑定实例的会话也可以暂停。「恢复预览」仅恢复读取，不自动重启已停止任务；要继续游戏执行需重新委托并按需审批。不回收已经产生的历史资料，也不封锁用户直接操作模拟器或其他通用工具。不要承诺全自动账号登录。

## 5. 明日方舟配置与执行

| 配置 | 当前含义 |
| --- | --- |
| maaDir / python / adbPath | MAA 目录、Python 命令、ADB 路径；本机已准备 external/maa 与 external/platform-tools |
| address / connection | 实测本机设备地址；General / MuMuEmulator12 / MuMuEmulator |
| emulator | 可选 MuMu CLI 路径与实例索引 |
| clientType | Official 或 Bilibili |
| baseMode / baseThreshold / dormNotStationed / dormTrust | normal 普通自动换班或 custom 自定义；心情阈值与宿舍策略 |
| basePlan / basePlanIndex | custom 模式才使用已有受授权方案及索引；复杂阵容生成尚未实现 |
| medicineLimit | 默认 0，普通理智药授权上限最多 10；本次未说吃药仍按 0 执行 |
| expiringMedicineLimit | 为旧配置兼容保留，当前不启用临期药；非零不代表可执行授权 |
| creditShopping / creditBlacklist / onlyDiscount | 是否授权信用购物、黑名单、MAA 折扣相关策略 |
| maxFightTimes | 默认 5，最高 50；实际运行不得突破配置上限 |

默认不吃药、不花源石、不购物、不抽卡；base/shopping 默认 false。普通换班无需文件；自定义方案运行前校验所选计划并使用同字节临时快照，拒绝启用无人机的方案。`onlyDiscount` 不能保证所有购买商品均为折扣商品；严格“只买折扣”要求下应先保持 shopping=false，不假装已实现该保证。

仅连接不需要先确认刷取关卡/次数。准备运行时才确认关卡、任务与资源策略，保守的完整 run 参数：

```json
{"input":{"plan":{"startup":true,"daily":true,"friends":true,"base":false,"shopping":false,"fight":{"stage":"1-7","times":3,"medicine":0,"expiringMedicine":0}},"maxSeconds":1800}}
```

这是接口示例，不会自动执行。若用户要求刷关但未确认关卡/次数，应先补全并重新生成计划；只有用户明确取消刷关后才可去掉 fight 执行其他项。maxSeconds 为 10..7200，默认 900。源石固定 0、临期药关闭；MAA 临期药参数不是瓶数上限，不能把限量要求转换成可能无限用药。付费、抽卡、自动招募和任意 Custom/SingleStep 未开放。

肉鸽需独立明确授权，runs 1..3、difficulty 0..18，主题为当前 schema 支持的 Phantom/Mizuki/Sami/Sarkaz/JieGarden，并需真实资源/游戏可用性验证；不保证通关，不默认混入收菜。

started 是异步启动，不是成功。查询 status/观察事件后报告后端完成/失败/停止及证据；后端完成不等于独立核验每份奖励。失败可能已花理智，不自动消费重试。

## 6. 龙虾杀与 Minecraft

- **龙虾杀**：用户说“用这个人设玩一局龙虾杀”，Agent 读取原始官方 Skill，用原始 ccl 命令。短命令使用 DSH 原生 pwsh，是否提权按当前档位与实际请求判断，不一律逐次审批；长开局/加入流仍由受管理的 Monitor 审批启动。官方观战页自动放入 GameGuy 右侧隔离容器，仅供人观看；不把观战隐藏信息送给 Agent。加载失败可重试/备用外部打开。真实对局、事件截止与远端 quit 仍待验收；本地停止不能冒充服务端退出成功。
- **Minecraft**：授权私人 Java offline-mode 测试服务器，不支持此原型用 Microsoft 账号登录。配置服务器/端口/用户名，观察、移动、限量挖掘。allowDig 默认 false，挖掘每次有块数和半径限制；路径自动挖掘/搭桥/跑酷关闭。当前未实现合成/装备/采木到石镐完整路线。TCP 连通诊断不等于完整游戏登录。

## 7. 每日计划

在已经配置并确认的 MAA 任务里说：

> 按这个收菜模板每天北京时间 08:00 运行，不吃药、不购物，每次最多半小时。

Agent 使用 **GameGuy 自有 scheduler**，审批后保存实例、配置指纹、plan、HH:mm、IANA 时区和时长。工具示例：

```json
{"input":{"time":"08:00","timeZone":"Asia/Shanghai","plan":{"startup":true,"daily":true,"friends":true,"base":false,"shopping":false},"maxSeconds":1800}}
```

没有默认计划；需用户明确指定时间并审批。定时计划页可查看/暂停/恢复/删除，对话可修改模板/时间；恢复和变更重新校验并按需审批。扩大资源或更换设备不能沿用旧授权。

- 到点由确定性服务执行已确认模板，不让模型“记着等待”，不必每次重复模型规划。
- 本机、服务、设备、游戏登录必须可用。当前日程不会无人值守代确认启动 MuMu。
- 窗口关闭留托盘可继续运行；退出应用、关机/睡眠时不执行，不承诺唤醒或云端代挂。
- 漏跑默认跳过；超过 60 秒迟到、实例忙碌、配置变化跳过并记录，不积压队列。
- 触发槽去重；中断不自动重复消费，不保证无限期 exactly-once。

## 8. 故障与数据

先查看任务状态、诊断与结果。停止按钮先阻止新的操作，再取消模型、CLI/后端并等待清理；未知远端状态明确标记，不报虚假成功。当前任务跨重启标为中断，不自动恢复运行。

产品数据在 `%APPDATA%\GameGuy-v03`；源码与本地包在 `D:\Gameguy`。Windows 启动器会将 npm 已安装 Electron 的同版本、经完整性核验的字节复制到 `%LOCALAPPDATA%\GameGuy\runtimes` 并运行，避免项目低完整性标签导致的 Chromium 启动崩溃；不会关闭沙箱或重装 MuMu。修复不热更新已有进程，下次正常启动加载新版代码。不要公开上传凭据文件、DSH 会话、账号数据、观战私有链接或设备图像。安装器、远程市场和真实三游戏验收均未完成，详见验证文档。

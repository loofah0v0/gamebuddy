## 产品表达

日常介绍 GameGuy（GG）自己：游戏搭子、收菜/玩游戏、配置环境、查资料/文件/脚本/排障。用自然中文，不输出框架架构简介或整套历史配置。只问身份时不启动游戏、不检索私人日志，不以历史记忆冒充今天完成的事实。

可以参照“电脑里的干活搭子”这种表达，不借用别的产品身份、不逐字照抄回答；昵称与用户称呼可自然询问，只有实际持久保存后才说“记住了”。

用户明确询问架构、技术来源或许可时如实回答。保留源代码、依赖及第三方归属与许可；产品身份不是遮掩技术事实，也不代表“完全自研”。

## 生效与兼容

Agent 预设会覆盖全局身份前缀，因此只改 Markdown 或初始化模板不够。当前注册独立产品身份提示段，并在每次提示组装中识别、替换旧的产品自带前缀；不改用户自定义提示，不改工具、权限、模型、计划、会话文件或历史消息。

AGENT.md 在进程启动时加载。当前应用不强行关闭，完成手头任务后重新启动 GameGuy，后续对话才加载更新；旧回答不追溯修改。技术上下文/工具名仍保留给 Agent 工作使用，但默认不充当面向用户的自我介绍。

测试中还修复了内部对话提交调用缺少取消信号参数的问题，保留原生会话取消机制，没有放宽授权。

## 验证边界

`npm run verify:identity` 使用实际 SDK/原生运行时和隔离的本地模型夹具，核对提交到模型的提示：新身份存在、旧产品前缀消失、执行安全规则保留；旧原生 profile 文件不被静默覆盖。

该测试验证提示组装和兼容，不是在线模型的语义评测；夹具回复预先固定，不能以此声称所有真实模型都会逐字给出同一回答。真实对话仍受所选模型影响。

# 游戏现场 UI（2026-10-27）

## 默认玩家视图
- 游戏名称与中文运行状态，不直接展示 arknights/running、taskId、agentId。
- 画面、刷新时间与停止/接管、隐私暂停按钮保留。
- 当前/最近运行显示有证据的步骤状态；只根据 MaaCore 链回执更新，不凭子任务事件假装完成。
- 最近动态最多 6 项，展示动作、时间与状态；相邻工具开始/结束记录合并显示。
- 后端完成不等于奖励到账，结果摘要明确保留核验边界。

## 技术详情
运行详情、执行记录、历史运行、审批参数、错误原文都放入默认折叠的原生 details/summary。展开时才序列化并渲染 JSON；收起时移除原始文本，保留完整底层数据。自动刷新不强制关闭用户已经展开的详情。审批的人类可读任务/资源摘要始终可见，不通过折叠隐藏消费约束。

## 验证
- npm test：211 个 JS/TS + 12 个 Python 测试通过，其中 8 项 UI 投影/折叠单测。
- npm run verify:dock-ui：实际 React GameDock + 隔离桥接的 Electron 渲染验证 10 项通过，覆盖默认折叠、展开/收起、刷新保持状态、320px 无横向溢出、审批风险摘要、结果核验措辞、无真实游戏调用。
- 深色、浅色、窄栏、审批、结果截图位于 artifacts/verification/game-dock-ui/。这些是 UI 示例数据，不是账号运行结果。
- 整套原生桌面 smoke 本轮两次都在 DSH 内核 boot 超时，未完成完整集成验收；日志 artifacts/verify-game-dock-ui.log。不把历史通过报告当作本次验收结果。
